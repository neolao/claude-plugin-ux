# Product

Rigplan — a desktop editor where lighting designers build the rig of a show: fixtures placed in a 3D viewport, patched and grouped.

## Platform & surface

- **Platform:** desktop (Electron), macOS and Windows
- **Devices & input:** mouse + keyboard, two screens
- **Runs with:** `npm run start`

## Users

| Role | Expertise | Frequency of use | Context of use | Main goal |
|---|---|---|---|---|
| Lighting designer | expert | daily | studio, then on site under time pressure | build and share a rig that matches the venue |

## Constraints

- **Brand / design system:** none
- **Accessibility target:** platform guidelines; VoiceOver and NVDA supported
- **Localization:** English only
- **Performance / offline / other:** the viewport must stay responsive while a file is written

## Vocabulary

| Term | Meaning | Never say |
|---|---|---|
| Fixture | One lighting device in the rig | Light, Lamp, Unit |
| Rig | All fixtures of a show | Setup, Plot |
| Show | The file holding one rig and its cues | Project, Document |
