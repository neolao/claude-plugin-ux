# Product — Lumen

## What it is

Lumen is a desktop lighting console for small theatres: the operator patches
fixtures, writes cues and runs the show from a laptop.

## Platform & surface

- **Platform:** desktop (Electron, macOS and Windows)
- **Devices & input:** mouse + keyboard; laptop screens from 1280 px wide
- **Runs with:** `npm run dev`

## Users

| Role | Expertise | Frequency of use | Context of use | Main goal |
|---|---|---|---|---|
| Light operator | expert | daily during a run | booth, in the dark, under time pressure | run the show without a missed cue |

## Constraints

- **Brand / design system:** none
- **Accessibility target:** none stated
- **Localization:** English only, no other language planned
- **Performance / offline / other:** works offline
