# Product — Rigger

Rigger is a Unity editor tool where technical artists set up and check character rigs inside the editor, next to the Inspector and the Scene view.

## Platform & surface

- **Platform:** game-engine tool (Unity editor 2022 LTS, macOS and Windows)
- **Devices & input:** mouse + keyboard, two monitors, the Rigger panel docked next to the Inspector; most artists run the editor's dark theme
- **Runs with:** open the project in Unity, Window > Rigger

## Users

| Role | Expertise | Frequency of use | Context of use | Main goal |
|---|---|---|---|---|
| Technical artist | expert | daily, all day | at the desk, editor open on both monitors, switching between Rigger, the Inspector and the Scene view every minute | a rig checked and exported before the animators need it |

## Jobs to be done

1. When a character model arrives, the technical artist wants to set up its rig and check every bone, so that the animators can start.
2. When a rig is checked, the technical artist wants to export it to the animation package, so that nothing is redone by hand.

## Constraints

- **Brand / design system:** none — the studio's tools follow the Unity editor look
- **Accessibility target:** none stated
- **Localization:** English
- **Performance / offline / other:** the panel must stay usable while a heavy scene is open

## Vocabulary

- **Rig:** the bone hierarchy and constraints of one character.
- **Bone:** one joint of the rig.
